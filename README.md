# GitHub AI Daily Trending

每天北京时间 10:00，由 GitHub Actions 自动抓取 [GitHub Trending](https://github.com/trending)（daily），筛选 AI 相关仓库，按当日新增 star 生成 Top 10 报告并提交到本仓库。

- 工作流：[.github/workflows/daily.yml](.github/workflows/daily.yml)
- 报告目录：[reports/](reports/)
- 手动触发：Actions → daily-github-ai-trending → Run workflow
